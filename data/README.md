# Data Folder

This folder is used for:

## Sample Documents (`sample_docs/`)
Store sample documents for the RAG exercises. The code will create sample files here during Session 3.

## Vector Database (`chroma_db/`)
The Chroma vector database will be stored here after running Session 3.

## Your Documents
Feel free to add your own documents to test RAG:
- `.txt` files
- `.pdf` files (requires `pypdf` package)
- `.md` files

## Note
Large files and the vector database are ignored by git (see `.gitignore`).
